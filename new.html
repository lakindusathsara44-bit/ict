උසස් පෙළ තොරතුරු හා සන්නිවේදන තාක්ෂණය

පද්ධති කළමනාකරණය දත්ත සමුදාය ජාලකරණය IoT විද්‍යුත් වාණිජ්‍යය වෙබ් සංවර්ධනය Python

1. පද්ධති කළමනාකරණය – මෙහෙයුම් පද්ධති (Operating Systems)

ඒකකය 05 – මෙහෙයුම් පද්ධති පිළිබඳ මූලික සංකල්ප හා කළමනාකරණය

1.1 මෙහෙයුම් පද්ධතියක් යනු කුමක්ද?

මෙහෙයුම් පද්ධතියක් (Operating System – OS) යනු පරිගණකයේ දෘඩාංග හා මෘදුකාංග අතර අතුරු මුහුණතක් ලෙස ක්‍රියා කරන පද්ධති මෘදුකාංගයකි. එය පරිශීලකයාට පරිගණකය පහසුවෙන් භාවිත කිරීමට මෙන්ම යෙදුම් මෘදුකාංග ක්‍රියාත්මක කිරීමට පදනම සපයයි.

ප්‍රධාන කාර්යයන්:
  • අතුරු මුහුණත් (Interfaces) ලබා දීම
  • ක්‍රියාවලි කළමනාකරණය (Process Management)
  • මතක කළමනාකරණය (Memory Management)
  • ගොනු පද්ධති කළමනාකරණය (File System Management)
  • උපාංග කළමනාකරණය (Device Management)
  • ආරක්ෂාව හා ආරක්ෂණය (Security & Protection)

1.2 මෙහෙයුම් පද්ධති වර්ගීකරණය

  • ඒක පරිශීලක – ඒක කාර්ය (Single-user – Single task): එකවර එක් පරිශීලකයෙකුට පමණක් එක් කාර්යයක් කිරීමට ඉඩ සලසයි. (උදා: MS-DOS)
  • ඒක පරිශීලක – බහු කාර්ය (Single-user – Multi task): එක් පරිශීලකයෙකුට එකවර කාර්ය කිහිපයක් කිරීමට ඉඩ සලසයි. (උදා: Windows, macOS)
  • බහු පරිශීලක – බහු කාර්ය (Multi-user – Multi task): පරිශීලකයන් කිහිප දෙනෙකුට එකවර කාර්ය කිහිපයක් කිරීමට ඉඩ සලසයි. (උදා: Linux, Unix, Windows Server)
  • තත්‍ය කාලීන (Real-time): කාර්යයන් නිශ්චිත කාල සීමාවන් තුළ සම්පූර්ණ කිරීමට නිර්මාණය කර ඇත. (උදා: ගුවන් ගමන් පාලන පද්ධති)
  • කාල විභජන (Time-sharing): බහු පරිශීලකයන්ට කාල කොටස් බෙදා දී පරිගණකය බෙදා ගැනීමට ඉඩ සලසයි.

1.3 ක්‍රියාවලි කළමනාකරණය (Process Management)

ක්‍රියාවලියක් යනු ක්‍රියාත්මක වන වැඩසටහනකි. මෙහෙයුම් පද්ධතිය ක්‍රියාවලි තත්ත්ව (Process States) කළමනාකරණය කරයි: නව (New), සූදානම් (Ready), ක්‍රියාත්මක (Running), අවහිර (Blocked), අවසන් (Terminated).

  • ක්‍රියාවලි පාලන බ්ලොක් (PCB): එක් එක් ක්‍රියාවලිය පිළිබඳ තොරතුරු ගබඩා කරන ව්‍යුහය.
  • සන්දර්භ මාරුව (Context Switching): එක් ක්‍රියාවලියක සිට තවත් ක්‍රියාවලියකට CPU මාරු කිරීම.
  • උපලේඛනගත කිරීම (Scheduling): ක්‍රියාවලි උපලේඛනගත කිරීමේ ප්‍රතිපත්ති (FCFS, SJF, Round Robin, Priority Scheduling).

1.4 මතක කළමනාකරණය (Memory Management)

  • භෞතික මතකය (Physical Memory) : RAM හි ඇති සැබෑ මතක ස්ථාන.
  • අතාත්වික මතකය (Virtual Memory): දෘඪ තැටියේ කොටසක් මතකයක් ලෙස භාවිත කිරීම (Paging, Segmentation).
  • මතක කළමනාකරණ ඒකකය (MMU): අතාත්වික ලිපින භෞතික ලිපින බවට පරිවර්තනය කරයි.

1.5 ගොනු පද්ධති කළමනාකරණය (File System Management)

  • ගොනු (Files) සහ නාමාවලි (Directories) කළමනාකරණය.
  • ගොනු වර්ග: .exe, .jpg, .txt, .docx, .pdf ආදිය.
  • ගොනු ධූරාවලිය (File Hierarchy) – මූල නාමාවලියෙන් ආරම්භ වන ව්‍යුහය.
  • ගොනු පද්ධති: FAT, NTFS, ext4 ආදිය.
  • ගොනු ආරක්ෂාව: මුරපද, ප්‍රවේශ අවසර (Read, Write, Execute).
  • ඛණ්ඩනය (Defragmentation) – ගොනු කොටස් යාබදව තැබීමෙන් කාර්ය සාධනය වැඩි දියුණු කිරීම.
වැදගත්: මෙහෙයුම් පද්ධතිය උපාංග ධාවක (Device Drivers) මගින් ආදාන/ප්‍රතිදාන උපාංග කළමනාකරණය කරයි. එසේම Spooling (උපාංග සමගාමී කිරීම) මගින් මුද්‍රණ යන්ත්‍ර වැනි උපාංග කාර්යක්ෂමව භාවිත කරයි.

2. දත්ත සමුදාය කළමනාකරණය (Database Management)

ඒකකය 08 – දත්ත සමුදා පද්ධති සැලසුම් හා සංවර්ධනය

2.1 දත්ත සමුදායක් යනු කුමක්ද?

දත්ත සමුදායක් (Database) යනු ක්‍රමානුකූලව සංවිධානය කරන ලද දත්ත සමූහයකි. දත්ත සමුදා කළමනාකරණ පද්ධතිය (DBMS) මගින් දත්ත ගබඩා කිරීම, ප්‍රවේශ වීම, යාවත්කාලීන කිරීම සහ කළමනාකරණය කිරීම සිදු කෙරේ.

2.2 දත්ත සමුදා ආකෘති (Database Models)

  • Flat-file: සරල ගොනු පද්ධතියක් ලෙස දත්ත ගබඩා කිරීම.
  • ධූරාවලි ආකෘතිය (Hierarchical): ගසක් වැනි ව්‍යුහයක් – එක්-බොහෝ සම්බන්ධතා.
  • ජාල ආකෘතිය (Network): බොහෝ-බොහෝ සම්බන්ධතා සහිත වඩාත් සංකීර්ණ ව්‍යුහය.
  • සම්බන්ධතා ආකෘතිය (Relational): වගු (Tables) මගින් දත්ත නිරූපණය කරයි. (වඩාත් ජනප්‍රිය)
  • වස්තු-සම්බන්ධතා ආකෘතිය (Object-Relational): වස්තු සහ සම්බන්ධතා යන දෙකම භාවිත කරයි.

2.3 ER ආකෘතිය (Entity-Relationship Model)

  • ආයතන (Entities): තථ්‍ය ලෝකයේ වස්තුවක් හෝ සංකල්පයක්. (උදා: ශිෂ්‍යයා, පාඨමාලාව)
  • ගුණාංග (Attributes): ආයතනයක ගුණාංග. (උදා: ශිෂ්‍ය ID, නම)
  • සම්බන්ධතා (Relationships): ආයතන අතර සම්බන්ධතා. (උදා: ශිෂ්‍යයා පාඨමාලාවක් හදාරයි)
  • ගණනීයතාව (Cardinality): සම්බන්ධතාවයේ ප්‍රමාණාත්මක බව. (1:1, 1:M, M:N)
ER සටහනක් (ER Diagram): ආයතන, ගුණාංග සහ සම්බන්ධතා ග්‍රාෆිකව නිරූපණය කරයි. එය සම්බන්ධතා ආකෘතියක් බවට පරිවර්තනය කළ හැක.

2.4 සම්බන්ධතා ආකෘතිය (Relational Model)

  • වගු (Tables) / සම්බන්ධතා (Relations): දත්ත ගබඩා කරන ප්‍රධාන ඒකක.
  • පේළි (Tuples): වගුවේ ඇති එක් එක් වාර්තාව.
  • තීරු (Attributes): වගුවේ ඇති එක් එක් ක්ෂේත්‍රය.
  • යතුරු (Keys):
    • ප්‍රාථමික යතුර (Primary Key): වාර්තාව අනන්‍යව හඳුනා ගනී.
    • විදේශ යතුර (Foreign Key): වෙනත් වගුවක ප්‍රාථමික යතුර හඳුනා ගනී.
    • අපේක්ෂක යතුර (Candidate Key): ප්‍රාථමික යතුර වීමට සුදුසු යතුරු.

2.5 SQL (Structured Query Language)

  • DDL (Data Definition Language): වගු නිර්මාණය, වෙනස් කිරීම, මකා දැමීම.
    CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE DATABASE, DROP DATABASE
  • DML (Data Manipulation Language): දත්ත ඇතුළත් කිරීම, යාවත්කාලීන කිරීම, මකා දැමීම, තෝරා ගැනීම.
    INSERT INTO, UPDATE, DELETE, SELECT
  • SELECT විමසුම්: WHERE, ORDER BY, JOIN (INNER JOIN, LEFT JOIN), GROUP BY, HAVING.
-- උදා: වගු නිර්මාණය CREATE TABLE ශිෂ්‍ය ( ශිෂ්‍ය_ID INT PRIMARY KEY, නම VARCHAR(50) NOT NULL, ලිපිනය VARCHAR(100) ); -- දත්ත ඇතුළත් කිරීම INSERT INTO ශිෂ්‍ය VALUES (1, 'අමරා', 'කොළඹ'); -- දත්ත තෝරා ගැනීම SELECT * FROM ශිෂ්‍ය WHERE නම LIKE 'අ%';

2.6 සාමාන්‍යකරණය (Normalization)

  • අවශ්‍යතාව: අතිරික්ත දත්ත අවම කිරීම, යාවත්කාලීන විෂමතා (Update Anomalies) මඟහැරීම.
  • පළමු සාමාන්‍ය ආකාරය (1NF): එක් එක් ක්ෂේත්‍රයේ පරමාණුක අගයන් තිබීම.
  • දෙවන සාමාන්‍ය ආකාරය (2NF): 1NF හා අර්ධ පරායත්තතා (Partial Dependencies) ඉවත් කිරීම.
  • තෙවන සාමාන්‍ය ආකාරය (3NF): 2NF හා සංක්‍රාන්ති පරායත්තතා (Transitive Dependencies) ඉවත් කිරීම.

3. දත්ත සන්නිවේදනය හා ජාලකරණය – IP ලිපින

ඒකකය 06 – දත්ත සන්නිවේදනය හා ජාලකරණය

3.1 සංඥා (Signals) සහ සන්නිවේදන මාධ්‍ය

  • ඇනලොග් සහ ඩිජිටල් සංඥා: ඇනලොග් – අඛණ්ඩ තරංග; ඩිජිටල් – විවික්ත (0,1) අගයන්.
  • මාර්ගෝපදේශිත මාධ්‍ය (Guided Media): Twisted Pair, Coaxial Cable, Fiber Optics.
  • මාර්ගෝපදේශ නොවන මාධ්‍ය (Unguided Media): ගුවන් විදුලි තරංග, මයික්‍රෝවේව්, චන්ද්‍රිකා.

3.2 ජාල ස්ථලක (Network Topologies)

  • බස් (Bus): සියලු උපාංග එක් පොදු කේබලයකට සම්බන්ධ වේ.
  • තාරකා (Star): සියලු උපාංග මධ්‍යම ස්විචයකට සම්බන්ධ වේ.
  • වළල්ල (Ring): උපාංග වළල්ලක් ලෙස සම්බන්ධ වේ.
  • ජාලක (Mesh): සෑම උපාංගයක්ම අනෙක් සියල්ලට සම්බන්ධ වේ.

3.3 ජාල උපාංග සහ ප්‍රොටෝකෝල

  • MAC ලිපින: උපාංගයේ භෞතික ලිපිනය (දෘඩාංග මට්ටම).
  • IP ලිපින: ජාලයේ උපාංගයක් හඳුනා ගැනීමට භාවිත කරන තාර්කික ලිපිනය.
  • IPv4: බිටු 32 ක ලිපිනයක් (උදා: 192.168.1.1). බිටු 8 බැගින් වූ කොටස් 4 කින් සමන්විතය.
  • IPv6: බිටු 128 ක ලිපිනයක් (උදා: 2001:0db8:85a3::8a2e:0370:7334).
  • උපජාලකරණය (Subnetting): IP ලිපින පරාසයක් කුඩා උපජාල ලෙස බෙදීම.
  • DHCP: ස්වයංක්‍රීයව IP ලිපින පැවරීම.
TCP/IP ආකෘතියේ ස්තර:
1. යෙදුම් (Application) – HTTP, FTP, SMTP
2. ප්‍රවාහන (Transport) – TCP, UDP
3. අන්තර්ජාල (Internet) – IP, ICMP
4. ජාල ප්‍රවේශ (Network Access) – Ethernet, Wi-Fi

3.4 වැදගත් ප්‍රොටෝකෝල

  • TCP: විශ්වාසනීය, සම්බන්ධතා-නැඹුරු ප්‍රවාහන ප්‍රොටෝකෝලය.
  • UDP: අවිශ්වාසනීය, සම්බන්ධතා-රහිත ප්‍රවාහන ප්‍රොටෝකෝලය.
  • HTTP/HTTPS: වෙබ් පිටු සන්නිවේදනය සඳහා.
  • DNS: වසම් නම් IP ලිපින බවට පරිවර්තනය කරයි.
  • FTP: ගොනු හුවමාරුව සඳහා.

4. අන්තර්ජාලයේ දේවල් (Internet of Things – IoT)

ඒකකය 11 – IoT පිළිබඳ මූලික සංකල්ප හා යෙදුම්

4.1 IoT යනු කුමක්ද?

IoT යනු භෞතික උපාංග, වාහන, ගෘහ උපකරණ සහ අනෙකුත් අයිතම සංවේදක, මෘදුකාංග සහ ජාල සම්බන්ධතා සමඟ සන්නද්ධ කර ඒවාට අන්තර්ජාලය හරහා දත්ත හුවමාරු කර ගැනීමට හැකියාව ලබා දීමේ සංකල්පයයි.

4.2 IoT හි ප්‍රධාන අංග

  • සංවේදක (Sensors): පරිසරයෙන් දත්ත රැස් කරයි (උදා: උෂ්ණත්වය, ආලෝකය, චලනය).
  • ක්‍රියාකාරක (Actuators): භෞතික ක්‍රියා සිදු කරයි (උදා: මෝටරයක් කරකැවීම, ආලෝකයක් දැල්වීම).
  • සම්බන්ධතාව (Connectivity): Wi-Fi, Bluetooth, Zigbee, LoRa, 5G ආදිය.
  • දත්ත සැකසුම (Data Processing): රැස් කළ දත්ත විශ්ලේෂණය කර ක්‍රියාමාර්ග ගැනීම.
  • අතුරු මුහුණත (User Interface): පරිශීලකයාට උපාංග පාලනය කිරීමට සහ දත්ත නැරඹීමට.

4.3 ක්ෂුද්‍ර පාලක පද්ධති (Microcontroller Systems)

  • Arduino Board: විවෘත-මූලාශ්‍ර ක්ෂුද්‍ර පාලක පුවරුවක්. ඇනලොග්/ඩිජිටල් ආදාන, ඩිජිටල් ප්‍රතිදාන, USB, බල සැපයුම.
  • Raspberry Pi: සම්පූර්ණ පරිගණකයක් වන කුඩා පුවරුවක්. Linux ධාවනය කළ හැක.
  • IDE (Integrated Development Environment): කේත සංස්කරණය, සම්පාදනය සහ උඩුගත කිරීම සඳහා.
සරල IoT යෙදුම්:
  • LED බල්බ දිලිසීම/නිවීම
  • ආලෝක සංවේදකය (LDR) මගින් ආලෝකය අනුව LED පාලනය
  • උෂ්ණත්ව සංවේදකය මගින් අධික උෂ්ණත්වයේ දී විදුලි පංකාව ක්‍රියාත්මක කිරීම
  • චුම්බක යතුරක් භාවිතයෙන් දොර විවෘත/වැසීම

5. විද්‍යුත් වාණිජ්‍යය (E-Commerce)

ඒකකය 12 – ව්‍යාපාර තුළ ICT භාවිතය

5.1 විද්‍යුත් වාණිජ්‍යය (E-Commerce) යනු කුමක්ද?

විද්‍යුත් වාණිජ්‍යය යනු අන්තර්ජාලය හරහා භාණ්ඩ හා සේවා මිලදී ගැනීම, විකිණීම සහ හුවමාරු කිරීමයි. එය ඩිජිටල් ආර්ථිකයේ ප්‍රධාන අංගයකි.

5.2 විද්‍යුත් වාණිජ්‍ය ආකෘති

  • B2B (Business to Business): ව්‍යාපාරිකයන් අතර වෙළඳාම.
  • B2C (Business to Consumer): ව්‍යාපාරිකයන්ගෙන් පාරිභෝගිකයන්ට වෙළඳාම.
  • C2C (Consumer to Consumer): පාරිභෝගිකයන් අතර වෙළඳාම (උදා: eBay).
  • C2B (Consumer to Business): පාරිභෝගිකයන් ව්‍යාපාරිකයන්ට සේවා සපයයි.
  • G2C (Government to Consumer): රජය පාරිභෝගිකයන්ට සේවා සපයයි.

5.3 විද්‍යුත් වාණිජ්‍යයේ ප්‍රතිලාභ

  • පාරිභෝගිකයින්ට පහසුව – 24×7 සාප්පු සවාරි.
  • පුළුල් වෙළඳපල ප්‍රවේශය – ගෝලීය ප්‍රේක්ෂකයින් වෙත ළඟා වීම.
  • පිරිවැය අඩු කිරීම – භෞතික ගබඩා සහ කාර්ය මණ්ඩලය අවශ්‍ය නොවේ.
  • වේගවත් ගනුදෙනු – ක්ෂණික ගෙවීම් සහ තහවුරු කිරීම්.

5.4 විද්‍යුත් වාණිජ්‍යයේ අභියෝග

  • ආරක්ෂාව – දත්ත කඩකිරීම්, වංචා.
  • පෞද්ගලිකත්වය – පාරිභෝගික තොරතුරු ආරක්ෂා කිරීම.
  • නීතිමය ගැටළු – බදු, රෙගුලාසි.
  • ඩිජිටල් බෙදීම – සමහර ප්‍රදේශවල අන්තර්ජාල ප්‍රවේශය නොමැතිකම.
ගෙවීම් ද්වාර (Payment Gateways): PayPal, Stripe, ශ්‍රී ලංකාවේ ඩිජිටල් ගෙවීම් පද්ධති. ආරක්ෂිත ගනුදෙනු සඳහා සංකේතනය (Encryption) සහ ඩිජිටල් අත්සන් භාවිතා කෙරේ.

6. වෙබ් සංවර්ධනය (Web Development)

ඒකකය 10 – වෙබ් අඩවි සංවර්ධනය (HTML5, CSS, PHP, MySQL)

6.1 වෙබ් පිටු සහ වෙබ් අඩවි

වෙබ් අඩවියක් යනු අන්තර්ජාලය හරහා ප්‍රවේශ විය හැකි අන්තර් සම්බන්ධිත වෙබ් පිටු සමූහයකි. වෙබ් පිටුවක් යනු HTML, CSS සහ JavaScript වැනි තාක්ෂණයන් භාවිතයෙන් නිර්මාණය කරන ලද ලේඛනයකි.

6.2 HTML (HyperText Markup Language)

  • වෙබ් පිටුවල ව්‍යුහය නිර්වචනය කරයි.
  • මූලික ව්‍යුහය: <html>, <head>, <title>, <body>
  • පාඨ හැඩතල ගැන්වීම: <h1>…<h6>, <p>, <br>, <b>, <i>, <u>
  • සබැඳි (Links): <a href="url"> සබැඳිය </a>
  • රූප (Images): <img src="image.jpg" alt="විස්තරය">
  • වගු (Tables): <table>, <tr>, <td>, <th>
  • ලයිස්තු (Lists): <ul>, <ol>, <li>
  • පෝරම (Forms): <form>, <input>, <select>, <textarea>, <button>
<html> <head><title>මගේ පිටුව</title></head> <body> <h1>ආයුබෝවන්!</h1> <p>මෙය මගේ පළමු වෙබ් පිටුවයි.</p> <a href="https://www.google.com">ගූගල් වෙත යන්න</a> </body> </html>

6.3 CSS (Cascading Style Sheets)

  • වෙබ් පිටුවල පෙනුම (වර්ණ, පිරිසැලසුම, අකුරු) පාලනය කරයි.
  • CSS ඇතුළත් කිරීමේ ක්‍රම: Inline, Internal ( <style> ), External ( <link> ).
  • තෝරා ගැනීම් (Selectors): Element, ID (#id), Class (.class), Group.
  • වැදගත් ගුණාංග: background-color, color, font-size, margin, padding, border, text-align.
/* CSS උදාහරණය */ body { background-color: #f0f8ff; font-family: Arial, sans-serif; } h1 { color: #1a4a6e; text-align: center; } .highlight { background-color: #e1edfa; padding: 10px; border-radius: 6px; }

6.4 PHP සහ MySQL – ගතික වෙබ් පිටු

  • PHP: සේවාදායක-පාර්ශ්ව ස්ක්‍රිප්ට් භාෂාවක්. වෙබ් පිටු ගතික කිරීමට භාවිත කරයි.
  • MySQL: දත්ත සමුදා කළමනාකරණ පද්ධතියක් (RDBMS).
  • PHP මගින් MySQL දත්ත සමුදායට සම්බන්ධ වී දත්ත ඇතුළත් කිරීම, යාවත්කාලීන කිරීම, මකා දැමීම සහ තෝරා ගැනීම කළ හැක.
  • පෝරම දත්ත හැසිරවීම: $_GET සහ $_POST සුපිරි ගෝලීය විචල්‍යයන්.
<?php // PHP සහ MySQL සම්බන්ධතා උදාහරණය $servername = "localhost"; $username = "root"; $password = ""; $dbname = "myDB"; $conn = new mysqli($servername, $username, $password, $dbname); if ($conn->connect_error) { die("සම්බන්ධතාව අසාර්ථකයි: " . $conn->connect_error); } $sql = "SELECT id, නම, ඊමේල් FROM පරිශීලක"; $result = $conn->query($sql); while($row = $result->fetch_assoc()) { echo "id: " . $row["id"]. " - නම: " . $row["නම"]. " - ඊමේල්: " . $row["ඊමේල්"]. "<br>"; } $conn->close(); ?>

6.5 වෙබ් අඩවි ප්‍රසිද්ධ කිරීම (Web Hosting)

  • වෙබ් අඩවියක් අන්තර්ජාලයේ ප්‍රසිද්ධ කිරීම සඳහා වෙබ් හෝස්ටින් සේවාවක් භාවිත කරයි.
  • නොමිලේ හෝස්ටින් සේවා (උදා: 000webhost, InfinityFree) හෝ ගෙවුම් හෝස්ටින් සේවා.
  • වසම් නමක් (Domain Name) ලියාපදිංචි කර ගැනීම.
  • වෙබ් අඩවියේ කාර්ය සාධනයට බලපාන සාධක: සේවාදායක වේගය, පිටු ප්‍රමාණය, ජාල ප්‍රමාදය.

7. Python ක්‍රමලේඛනය (Python Programming)

ඒකකය 09 – ක්‍රමලේඛනය (Python භාෂාව භාවිතයෙන්)

7.1 Python යනු කුමක්ද?

Python යනු ඉහළ මට්ටමේ, අර්ථකථනය කළ, සාමාන්‍ය-අරමුණු ක්‍රමලේඛන භාෂාවකි. එය සරල, කියවීමට පහසු වාක්‍ය ඛණ්ඩයක් සහිත වන අතර විවිධ ක්‍ෂේත්‍රවල භාවිත වේ.

7.2 Python හි මූලික සංකල්ප

  • විචල්‍ය (Variables): දත්ත ගබඩා කිරීමට භාවිත කරයි. (උදා: x = 5, name = "අමරා")
  • දත්ත වර්ග (Data Types): int, float, str, bool, list, tuple, dict.
  • කාරක (Operators): ගණිතමය (+, -, *, /), සම්බන්ධක (<, >, ==, !=), තාර්කික (and, or, not).
  • පාලන ව්‍යුහ (Control Structures):
    • තීරණ (Selection): if, elif, else
    • පුනරාවර්තන (Repetition): for, while loops
  • ශ්‍රිත (Functions): නැවත භාවිත කළ හැකි කේත කොටස්. def යතුරු පදයෙන් අර්ථ දක්වයි.
# Python මූලික උදාහරණ # විචල්‍ය සහ දත්ත වර්ග name = "සමන්" age = 20 height = 5.8 is_student = True # පාලන ව්‍යුහ if age >= 18: print(name + " වැඩිහිටියෙකි.") else: print(name + " බාල වයස්කාරයෙකි.") # ශ්‍රිතයක් def greet(person): return "ආයුබෝවන්, " + person + "!" print(greet(name))

7.3 දත්ත ව්‍යුහ (Data Structures)

  • ලැයිස්තු (Lists): වෙනස් කළ හැකි, අනුක්‍රමික දත්ත එකතුවක්. (උදා: fruits = ["apple", "banana", "orange"])
  • ටියුපල් (Tuples): වෙනස් කළ නොහැකි අනුක්‍රමයක්. (උදා: colors = ("red", "green", "blue"))
  • ශබ්දකෝෂ (Dictionaries): යතුරු-අගය යුගල ගබඩා කරයි. (උදා: student = {"name": "නිෂා", "age": 22})

7.4 ගොනු හැසිරවීම (File Handling)

  • ගොනු විවෘත කිරීම: open("filename", "mode") – "r" කියවීම, "w" ලිවීම, "a" එකතු කිරීම.
  • ගොනුවකින් කියවීම: read(), readline(), readlines()
  • ගොනුවකට ලිවීම: write()
  • ගොනු වසා දැමීම: close()
# ගොනු හැසිරවීමේ උදාහරණය # ගොනුවකට ලිවීම file = open("data.txt", "w") file.write("මෙය පළමු පේළියයි.\n") file.write("මෙය දෙවන පේළියයි.") file.close() # ගොනුවකින් කියවීම file = open("data.txt", "r") content = file.read() print(content) file.close()

7.5 දත්ත සමුදාය සමඟ Python

  • Python මගින් MySQL, SQLite, PostgreSQL වැනි දත්ත සමුදා සමඟ සම්බන්ධ විය හැක.
  • MySQL සමඟ සම්බන්ධ වීමට mysql-connector-python හෝ PyMySQL භාවිත කරයි.
  • SQL විමසුම් ක්‍රියාත්මක කිරීමට cursor.execute() භාවිත කරයි.
# MySQL සමඟ Python සම්බන්ධතා උදාහරණය import mysql.connector conn = mysql.connector.connect( host="localhost", user="root", password="", database="myDB" ) cursor = conn.cursor() cursor.execute("SELECT * FROM පරිශීලක") for row in cursor.fetchall(): print(row) conn.close()

7.6 සෙවීම් සහ වර්ග කිරීමේ ඇල්ගොරිතම

  • අනුක්‍රමික සෙවීම (Sequential Search): ලැයිස්තුවක් ආරම්භයේ සිට අවසානය දක්වා සොයයි.
  • බුබුලු වර්ග කිරීම (Bubble Sort): යාබද මූලද්‍රව්‍ය සංසන්දනය කර හුවමාරු කරයි.

8. ගුරු මාර්ගෝපදේශයට අනුව වැදගත් කරුණු

  • ස්වයං ඉගෙනීම: ශිෂ්‍යයන් ස්වයං ඉගෙනීම සඳහා දිරිමත් කළ යුතු අතර, ගුරුවරයා මග පෙන්වීම සපයයි.
  • ප්‍රායෝගික සැසි: න්‍යායාත්මක දැනුම ප්‍රායෝගිකව යෙදීමට පරිගණක විද්‍යාගාර සැසි අත්‍යවශ්‍ය වේ.
  • තක්සේරුව: අඛණ්ඩ තක්සේරුව (Formative Assessment) සහ අවසාන තක්සේරුව (Summative Assessment) යන දෙකම වැදගත් වේ.
  • ව්‍යාපෘතිය (Project): 13 වන ශ්‍රේණියේ දී පුද්ගලික ව්‍යාපෘතියක් සම්පූර්ණ කළ යුතු අතර එයට පැය 30 ක් වෙන් කර ඇත.
  • සම්පත්: ජාතික අධ්‍යාපන ආයතනයේ වෙබ් අඩවිය (www.nie.lk) මගින් අමතර සම්පත් ලබා ගත හැක.
  • නව ප්‍රවණතා: ක්‍වොන්ටම් පරිගණනය, ජෛව-ආනුභාවික පරිගණනය, වලාකුළු පරිගණනය, යන්ත්‍ර ඉගෙනීම යනාදිය පිළිබඳ දැනුවත් වීම වැදගත්.

මෙම සටහන් මගින් උසස් පෙළ තොරතුරු හා සන්නිවේදන තාක්ෂණය විෂයයේ ප්‍රධාන ඒකක හතක් ආවරණය කරයි:

  • පද්ධති කළමනාකරණය (OS): මෙහෙයුම් පද්ධති, ක්‍රියාවලි කළමනාකරණය, මතක කළමනාකරණය, ගොනු පද්ධති.
  • දත්ත සමුදාය: ආකෘති, ER රූප සටහන්, SQL, සාමාන්‍යකරණය.
  • ජාලකරණය සහ IP: සංඥා, මාධ්‍ය, ජාල ස්ථලක, TCP/IP, IP ලිපින, උපජාලකරණය.
  • IoT: සංවේදක, ක්‍රියාකාරක, ක්ෂුද්‍ර පාලක, යෙදුම්.
  • විද්‍යුත් වාණිජ්‍යය: ආකෘති, ප්‍රතිලාභ, අභියෝග, ගෙවීම් ද්වාර.
  • වෙබ් සංවර්ධනය: HTML, CSS, PHP, MySQL, හෝස්ටින්.
  • Python: මූලික සංකල්ප, දත්ත ව්‍යුහ, ගොනු හැසිරවීම, දත්ත සමුදා සම්බන්ධතා.
